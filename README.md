# Parametric Tropical Cyclone Wind Profiles for the Western North Pacific

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.21357411.svg)](https://doi.org/10.5281/zenodo.21357411)

Analysis code and processed data for:

> Zerrudo, J. B., and M. S. Bala (2026). *A Comparison of Parametric Tropical
> Cyclone Wind Profiles for the Western North Pacific.* Tropical Cyclone Research
> and Review (submitted).

This repository reproduces every table and figure in the paper. It is
self-contained: the processed input data, the wind-profile library, all analysis
scripts, and a full set of reference outputs are included.

---

## 1. Requirements

Python 3.9+ with `numpy`, `pandas`, `scipy`, `matplotlib`.

Optional:
- `global-land-mask` (only for the Figure 1 domain map)
- `tcwindprofile` (only if you re-run the Tao 2026 predictions in script 03)

```
pip install numpy pandas scipy matplotlib global-land-mask tcwindprofile
```

## 2. Data files

All inputs are processed derivatives of public best-track data (see Provenance
below); they are keyed row-for-row so the scripts run without any assembly step.

| File | Contents |
|------|----------|
| `snapshot_catalog.csv` | Per-fix catalog (SID, ISO_TIME, BASIN, LON/LAT, USA_WIND, USA_RMW, wind-radius quadrants). Used for the `BASIN == 'WP'` filter and the track map. |
| `metrics_by_snapshot.csv` | Per-snapshot observed radii (`OBS_R34/R50/R64`) plus the six models' predictions and errors (`<Model>_<R>`, `<Model>_<R>_ERR`), keyed by `idx`. |
| `t26_predictions.csv` | Tao (2026) predictions on the same rows (idx-aligned), pre-generated by script 03. |
| `wind_profiles.py` | Model implementations used by the re-fit in script 04. |

## 3. Run order

Run each script from inside this folder.

```
python 01_diagnose_basin_contamination.py   # basin filter: 625 non-WP fixes (18 storms) removed -> 18,147 fixes / 512 storms
python 02_build_wnp_tables.py               # -> table1_wnp.csv, table2_wnp.csv
python 04_recent_era_and_refit.py           # era-stratified RMSE + WNP re-fit demonstration
python 05_regenerate_figures.py             # -> fig1..fig7 .png
python 03_tao2026_model.py                  # OPTIONAL, slow: regenerates t26_predictions.csv
```

Pre-generated reference outputs for every step are in `outputs/`, so you can
check a run without executing anything.

## 5. Tao (2026) flagging

Tao (2026) needs an R34 size input, whereas the other six models take Rmax. To
compare on equal footing it is driven from Rmax by inverting Chavas & Knaff
(2022) to infer R34. Its R34 is therefore an inferred size input, not an
independent prediction, while its R50 and R64 are genuine predictions. Every R34
Tao entry is flagged (italicised in the tables; hatched in the figures) so this is
never mistaken.

## 6. Data provenance and licensing

The processed CSVs are derived from public tropical-cyclone best-track data:

- **IBTrACS v04r01**, western North Pacific (NOAA National Centers for
  Environmental Information). Knapp, K. R., et al. (2010), *The International Best
  Track Archive for Climate Stewardship (IBTrACS).* Bull. Amer. Meteor. Soc.,
  91, 363-376.
- **JTWC extended best track** wind radii (U.S. Joint Typhoon Warning Center).

These sources are public; the derivatives are redistributed here solely to make
the analysis reproducible. Please cite the sources above when using the data.
