================================================================================
TCRR-2026-0037  -  Revision analysis bundle (runnable)
A Comparison of Parametric Tropical Cyclone Wind Profiles for the WNP
================================================================================

This folder is SELF-CONTAINED. The three input datasets, the wind-profile
library, all five analysis scripts, and a full set of pre-generated reference
outputs are included. You do not have to assemble anything.

--------------------------------------------------------------------------------
1. REQUIREMENTS
--------------------------------------------------------------------------------
  python 3.9+  with:  numpy  pandas  scipy  matplotlib
  optional (only for the Figure 1 domain map):   pip install global-land-mask
  optional (only if you re-run script 03):        pip install tcwindprofile

  Windows CMD one-liner for the extras:
     pip install numpy pandas scipy matplotlib global-land-mask tcwindprofile

--------------------------------------------------------------------------------
2. DATA FILES (already in this folder)
--------------------------------------------------------------------------------
  snapshot_catalog.csv      per-fix catalog: SID, ISO_TIME, BASIN, LON/LAT,
                            USA_WIND ... (used for the BASIN=='WP' filter and
                            the track map). All basins present; scripts filter.
  metrics_by_snapshot.csv   per-snapshot observed radii (OBS_R34/R50/R64) and
                            the six models' predictions + errors (<Model>_<R>
                            and <Model>_<R>_ERR), keyed by idx.
  t26_predictions.csv       Tao (2026) predictions on the SAME rows (idx-aligned),
                            pre-generated by script 03 so you can skip that slow
                            step. Columns Tao2026_R34/R50/R64 (+ _ERR).
  wind_profiles.py          model implementations (needed by script 04's re-fit).

--------------------------------------------------------------------------------
3. RUN ORDER  (run each from inside this folder)
--------------------------------------------------------------------------------
  python 01_diagnose_basin_contamination.py
        Shows the basin contamination we corrected: 625 non-WP fixes (18 storms)
        removed -> true WNP sample = 18,147 fixes / 512 storms. Ranking unchanged.

  python 02_build_wnp_tables.py            -> table1_wnp.csv, table2_wnp.csv
        Table 1 (six core models, overall error + storm-level bootstrap 95% CIs)
        and Table 2 (R34 bias by intensity / latitude / size).
        Tao (2026) is added to Table 2, FLAGGED as "[R34 inferred]".

  python 04_recent_era_and_refit.py        -> console
        (a) RMSE over 2001-2024, 2016-2024, 2020-2024 (ranking is stable);
        (b) WNP re-fit demo: Rankine alpha(Vmax,|lat|) 59.3->52.7 nm and
            Willoughby X1 45.8->45.3 nm (marginal; ranking unchanged).
        Tao included and flagged.

  python 05_regenerate_figures.py          -> fig1..fig7 .png
        Regenerates every figure. Tao (2026) is included in ALL figures and is
        always FLAGGED (see section 5).

  python 03_tao2026_model.py               -> t26_predictions.csv   (OPTIONAL)
        Regenerates the Tao predictions from scratch. SLOW (inverts Chavas &
        Knaff 2022 per snapshot, ~minutes). Not needed - output already shipped.

--------------------------------------------------------------------------------
4. FIGURE FILENAME  ->  MANUSCRIPT FIGURE NUMBER
--------------------------------------------------------------------------------

  is placed first in the paper:

     fig7_domain_map.png        =  Figure 1  (study domain / all tracks)
     fig1_overall_boxplots.png  =  Figure 2  (error box plots)
     fig2_r34_by_intensity.png  =  Figure 3  (R34 bias by intensity)

     fig6_rmse_summary.png      =  Figure 7  (RMSE by model and threshold)

--------------------------------------------------------------------------------
5. HOW TAO (2026) IS FLAGGED, AND WHY
--------------------------------------------------------------------------------
  Tao (2026) needs an R34 SIZE input, whereas the other six models take Rmax.
  To compare on equal footing we drive Tao from Rmax by inverting Chavas & Knaff
  (2022) to infer R34. Therefore Tao's R34 is NOT an independent prediction - it
  is essentially the inferred size input - while its R50 and R64 ARE genuine
  predictions. Every R34 Tao entry is flagged so this is never mistaken:

     Table 1   : Tao R34 value italicised (in the manuscript).
     Table 2   : row label "Tao (2026) [R34 inferred]".
     Fig 2 (box plots)  : Tao R34 box hatched (////).
     Figs 3-5 (bar charts): Tao bars hatched, legend "Tao 2026 (R34 inf.)".
     Fig 6 (scatter)    : Tao panel titled "Tao 2026 (R34 inferred)".
     Fig 7 (RMSE)       : Tao R34 bar hatched, with an explanatory note.

  Take-away: Tao is competitive at the inner core (R64 RMSE 17.4 nm, ~ Willoughby
  and CLE15) but underestimates the outer radii (R50 bias about -18 nm), which is
  largely inherited from the Rmax->R34 size inference.
